# Bhaag Didi Bhaag - Finalized Version ( For Entertainment Purpose Only )

A browser and WebView-compatible endless runner game built using HTML5 Canvas, JavaScript, and CSS.  
The game is optimized for mobile browsers and WebIntoApp APK WebView environments.

This project features dynamic gameplay, boss battles, vibration detection, orientation-based physics, and responsive design.

---

## 📌 Features

### 🎮 Gameplay
- Endless runner style game
- Jump to avoid obstacles
- Auto-firing bullets in boss phase
- Dynamic boss fight system
- Score-based progression
- Explosion and story ending sequence

### 📱 Platform Support
- Web browsers (Chrome, Firefox, etc.)
- Android WebView (WebIntoApp APK)
- Platform detection (APK vs Browser)

### 🔊 Audio System
- Background music
- Jump, collision, and explosion sounds
- Boss warning and battle themes
- Smooth fade-in/out effects
- Auto unlock on first user interaction

### 📳 Vibration Support
- Vibration capability detection
- Session-based caching
- Popup warning if vibration is unavailable
- Separate logic for APK and browser

### 📐 Responsive Design
- Works in portrait and landscape mode
- Orientation-based physics
- Auto resizing on screen rotation
- Device pixel ratio handling

### ⚙️ Advanced UI
- Loader with fake progress
- Pause menu
- Restart / Exit system
- Slide panel with redirect
- Fullscreen mode (browser)
- Instagram header link

### 🧠 Smart Game Logic
- Asset preloading system
- Collision optimization
- Boss hitbox trimming
- Hint system for new players
- Auto exit when app is hidden
- Session/login handling
